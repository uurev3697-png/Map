# Маршрут — интерактивная карта с построением маршрутов

Веб-приложение на React: карта с переключаемыми слоями и построением маршрутов из точки А в точку Б
сразу **пешком и на машине**. У каждого маршрута есть время, расстояние, время прибытия и
пошаговые инструкции.

**Стек:** Vite · React · TypeScript · Tailwind CSS · Framer Motion · MapLibre GL JS ·
`@vis.gl/react-google-maps` (необязательно).

## Возможности

**Карта**
- **Слои:** «Схема» (OpenFreeMap), «Спутник» (Esri World Imagery), «Тёмная» (своя ночная палитра в духе 2ГИС) и «Google» (если задан ключ).
- **3D:** кнопка «3D» наклоняет карту и показывает объёмные здания.
- **Линейка:** кнопка с линейкой. Клики по карте ставят точки, над каждой подписано накопленное расстояние, внизу показана общая длина. Точки можно перетаскивать, есть «отменить последнюю» и «очистить», выход по Esc.
- **Погода в моём местоположении:** плашка в углу карты с температурой и городом. По нажатию открывается «ощущается как», ветер, влажность и прогноз на 6 часов. Если доступ к геолокации уже разрешён, плашка появляется сама.
- **«Где я»:** синяя точка с пульсацией и конусом направления (по компасу или GPS-курсу).
- **Зимний режим** (кнопка-снежинка, по умолчанию включён с ноября по февраль): заснеженная карта днём и ночью, снегопад, снежные шапки на панели и маркерах.
- **Новогодние детали:** с 1 декабря по 15 января в зимнем режиме по краю панели висит гирлянда, а 31 декабря и 1 января вместо маркера «Б» стоит ёлочка. Посмотреть заранее можно, добавив к адресу `?newyear`.

**Навигация «В путь»**
- **Запуск:** кнопка «В путь» под карточками маршрута. Навигация ведёт от того места, где вы сейчас: если старт маршрута в другом месте, путь перестраивается от текущей позиции.
- **Камера:** следует за вами с наклоном и поворотом по направлению движения. Позиция показана стрелкой в нижней трети экрана, пройденная часть линии становится серой.
- **Сверху:** следующий манёвр крупно («200 м — поверните направо на …») и «Затем: …».
- **Снизу:** оставшиеся время и расстояние, время прибытия, полоса прогресса и кнопка «Завершить».
- **Голос:** подсказки по-русски (Web Speech API) с выключателем. Пороги объявлений: пешком 150/40/12 м, на велосипеде 300/90/25 м, на машине 800/300/70 м.
- **Сход с маршрута:** путь сам перестраивается от текущего места, пройденные остановки убираются.
- **Экран:** во время поездки не гаснет (Screen Wake Lock API).
- **Управление картой:** если сдвинуть карту рукой, слежение приостанавливается. Кнопка «Вернуться к маршруту» включает его снова.
- **Прибытие:** «Вы прибыли!».
- **«Демо-поездка»:** проехать маршрут виртуально (ускорено, примерно 45 секунд), чтобы посмотреть навигацию без GPS.

**Маршруты**
- **Три способа передвижения:** пешком, на велосипеде и на машине, считаются одновременно.
- **Неактивные маршруты:** рисуются полупрозрачной линией (пешком — точками, на велосипеде — штрихами).
- **Задать точки можно:**
  - поиском с автодополнением (Photon от Komoot, debounce, отмена устаревших запросов);
  - кликом по карте;
  - кнопкой «Моё местоположение».
- **Промежуточные остановки** (до трёх): добавляются кнопкой, удаляются крестиком, порядок меняется перетаскиванием за букву. Маркеры можно таскать по карте.
- **Альтернативные варианты:** показываются, если сервис нашёл их (обычно для длинных маршрутов). Выбрать вариант можно чипом в панели или кликом по серой линии на карте.
- **Время:** «Отправление сейчас», «Отправиться в…» или «Прибыть к…». Карточки показывают время прибытия или выезда (без учёта пробок).
- **Профиль высот** с набором и потерей высоты (Open-Meteo Elevation API).
- **Пошаговые инструкции:** по клику на шаг камера летит к нему.
- **Пролёт:** камера с наклоном пролетает вдоль маршрута.

**Удобство**
- **Ссылка на маршрут:** точки и способ передвижения хранятся в адресе страницы. Кнопка «Поделиться» копирует ссылку (на телефоне открывает системное меню «Поделиться»).
- **Открыть маршрут** в Яндекс Картах, 2ГИС или Google Картах.
- **Дом и Работа:** карточки «Мои места» в панели и чипы в подсказках. Первое нажатие открывает окно «Где ваш дом?»: адрес задаётся поиском, по текущему местоположению или из точек маршрута. Дальше одно касание строит маршрут от вашего местоположения. Карандаш у карточки меняет или удаляет адрес.
- **Избранное:** звёздочка ☆ у заполненной точки маршрута или у адреса в подсказках. Избранные места появляются чипами в «Мои места». Недавние поиски тоже сохраняются (всё хранится локально в браузере).
- **Погода в точке Б:** температура и иконка рядом с адресом (Open-Meteo).
- **PWA:** приложение можно установить на телефон или компьютер. Оболочка и недавно просмотренные тайлы карты кэшируются.

**Интерфейс**
- Светлая и тёмная тема, стеклянные панели, плавные анимации, скелетоны.
- На десктопе боковая панель, на телефоне нижняя шторка со свайпом.
- **Обработка ошибок:** нет сети, маршрут не найден, слишком далеко, лимит API, неверный ключ. Ошибки показываются уведомлениями.

### Установка как приложения (PWA)

Работает только по HTTPS (например, на Vercel) или на `localhost` в production-сборке (`npm run build && npm run preview`).
- **Android / Chrome:** меню браузера → «Установить приложение».
- **iPhone / Safari:** «Поделиться» → «На экран „Домой“».
- **Компьютер / Chrome, Edge:** значок установки в адресной строке.

## Быстрый старт

Нужен Node.js 20+.

```bash
npm install
cp .env.example .env   # ключи необязательны — без них всё работает
npm run dev            # http://localhost:5173
```

Другие команды:

```bash
npm run build     # production-сборка в dist/
npm run preview   # локальный просмотр сборки
npm run lint      # oxlint
```

## Переменные окружения

Все ключи хранятся только в `.env`. Этот файл уже в `.gitignore`, в репозиторий попадает только `.env.example`.

| Переменная                  | Обязательна | Что делает                                                                 |
| --------------------------- | ----------- | -------------------------------------------------------------------------- |
| `VITE_ORS_API_KEY`          | нет         | Роутинг через OpenRouteService. Без ключа используются публичные серверы OSRM (routed-foot / routed-bike / routed-car). |
| `VITE_GOOGLE_MAPS_API_KEY`  | нет         | Включает слой «Google». Без ключа пункт скрыт.                             |
| `VITE_GOOGLE_MAPS_MAP_ID`   | нет         | Map ID для векторных карт Google. Без него используется `DEMO_MAP_ID`.      |

> ⚠️ Переменные с префиксом `VITE_` попадают в клиентский бандл, и их видно в браузере. Это нормально
> для ключей, которые предназначены для фронтенда. Обязательно **ограничьте ключи по домену**
> (см. ниже).

### Как получить бесплатный ключ OpenRouteService

1. Зарегистрируйтесь на <https://openrouteservice.org/dev/#/signup>.
2. В личном кабинете (**Dashboard → Tokens**) создайте токен с типом **Standard** (бесплатный тариф).
3. Скопируйте ключ в `.env`:
   ```
   VITE_ORS_API_KEY=ваш_ключ
   ```
4. Перезапустите `npm run dev`.

С ключом ORS инструкции приходят сразу на русском языке. На бесплатном тарифе есть дневные и
поминутные лимиты, при превышении приложение покажет уведомление «Превышен лимит запросов».

### Как получить ключ Google Maps

1. Откройте <https://console.cloud.google.com/> и создайте проект.
2. Подключите биллинг-аккаунт. Google требует его даже для бесплатной квоты.
3. В разделе **APIs & Services → Library** включите **Maps JavaScript API**.
4. В разделе **APIs & Services → Credentials** нажмите **Create credentials → API key**.
5. Ограничьте ключ (**Edit API key**):
   - *Application restrictions* → **Websites**. Добавьте `http://localhost:5173/*` и домен продакшена,
     например `https://your-app.vercel.app/*`.
   - *API restrictions* → **Maps JavaScript API**.
6. Необязательно: в **Google Maps Platform → Map management** создайте Map ID (тип JavaScript, Vector)
   и укажите его в `VITE_GOOGLE_MAPS_MAP_ID`.
7. Запишите ключ в `.env`:
   ```
   VITE_GOOGLE_MAPS_API_KEY=ваш_ключ
   ```

Google Maps подключается **только** через официальный Maps JavaScript API. Тайлы Google в MapLibre
не загружаются, потому что это нарушает условия использования Google. В режиме Google маршрут
по-прежнему считает наш слой сервисов (ORS/OSRM) и рисует его через `google.maps.Polyline`.

## Деплой на Vercel

**Через веб-интерфейс:**

1. Загрузите репозиторий на GitHub.
2. На <https://vercel.com/new> импортируйте репозиторий. Vercel сам определит Vite:
   - Build Command: `npm run build`
   - Output Directory: `dist`
3. В **Settings → Environment Variables** добавьте нужные переменные (`VITE_ORS_API_KEY`,
   `VITE_GOOGLE_MAPS_API_KEY`, `VITE_GOOGLE_MAPS_MAP_ID`) для окружений Production и Preview.
4. Нажмите **Deploy**. Переменные подставляются при сборке, поэтому после их изменения нужен
   повторный деплой (**Deployments → Redeploy**).
5. Добавьте домен Vercel в ограничения ключа Google (см. выше).

**Через CLI:**

```bash
npm i -g vercel
vercel                 # первый деплой (preview)
vercel env add VITE_ORS_API_KEY
vercel --prod          # продакшен
```

Приложение одностраничное, без роутера, поэтому дополнительный `vercel.json` не нужен.

## Архитектура

```
src/
  services/                  ← слой сервисов, не зависит от UI
    types.ts                 ← LngLat, Route, RouteStep, Place, TravelMode (foot / bike / car)
    elevation.ts             ← профиль высот (Open-Meteo Elevation)
    weather.ts               ← погода в точке (Open-Meteo Forecast)
    errors.ts                ← ServiceError (not-found / too-far / network / rate-limit / auth) + request()
    routing/
      types.ts               ← интерфейс RoutingProvider: route(mode, points[], { alternatives })
      ors.ts                 ← OpenRouteService (foot-walking, cycling-regular, driving-car)
      osrm.ts                ← OSRM routing.openstreetmap.de (routed-foot, routed-bike, routed-car)
      osrmInstructions.ts    ← русские формулировки манёвров для OSRM
      index.ts               ← выбор провайдера: ORS при наличии ключа, иначе OSRM
    geocoding/
      types.ts               ← интерфейс GeocodingProvider (search + reverse)
      photon.ts              ← Photon (Komoot)
      index.ts               ← активный геокодер
  map/
    MapView.tsx              ← MapLibre: стили, маркеры, слои маршрута, камера, 3D
    mapTheme.ts              ← ночная и зимние палитры поверх стиля OpenFreeMap
    flyAlong.ts              ← пролёт камеры вдоль маршрута
    GoogleMapView.tsx        ← Google Maps (загружается лениво, только с ключом)
    routeLayers.ts           ← слои линии и анимация прорисовки (line-gradient)
    styles.ts                ← описания слоёв карты и цвета маршрутов
    markers.ts               ← DOM кастомных маркеров А/Б
  hooks/                     ← useRoutePlanner, useSuggestions, useTheme, …
  components/                ← панель, поля, карточки, инструкции, шторка, уведомления
  lib/format.ts              ← «1 ч 25 мин», «12,4 км», время прибытия/выезда
  lib/share.ts               ← ссылка на маршрут и ссылки на Яндекс / 2ГИС / Google
  lib/places.ts              ← история и избранное (localStorage)
public/
  manifest.webmanifest, sw.js, icons/  ← PWA
```

### Как подключить другой провайдер (GraphHopper, Google Routes и др.)

1. Создайте класс, реализующий `RoutingProvider` из `src/services/routing/types.ts`:
   ```ts
   export class GraphHopperProvider implements RoutingProvider {
     readonly id = 'graphhopper'
     readonly name = 'GraphHopper'
     async route(mode, points, { signal, alternatives }) { /* … вернуть Route[] — основной первым */ }
   }
   ```
2. Ошибки бросайте как `ServiceError` с нужным `kind`, тогда UI сам покажет понятное уведомление.
3. Подключите класс в `src/services/routing/index.ts`.

Геокодер (например, Nominatim) подключается так же: реализуйте `GeocodingProvider` и укажите его в
`src/services/geocoding/index.ts`.

## Данные и условия использования

- Картографические данные: © участники [OpenStreetMap](https://www.openstreetmap.org/copyright).
- Векторные тайлы: [OpenFreeMap](https://openfreemap.org/) и OpenMapTiles.
- Спутник: Tiles © Esri. Source: Esri, Maxar, Earthstar Geographics, and the GIS User Community.
- Поиск: [Photon](https://photon.komoot.io/) от Komoot. Публичный инстанс предназначен для
  умеренной нагрузки, поэтому запросы идут с debounce (350 мс), не чаще одного на ввод, от 3 символов,
  а устаревшие запросы отменяются. Для высокой нагрузки разверните свой Photon.
- Высоты и погода: [Open-Meteo](https://open-meteo.com/) (бесплатно для некоммерческого использования, без ключа).
  Данные о высотах — Copernicus DEM.
- Маршруты без ключа: публичные серверы OSRM от FOSSGIS
  ([routing.openstreetmap.de](https://routing.openstreetmap.de/)). Они рассчитаны на некоммерческое
  использование. Для продакшена с трафиком используйте ORS с ключом или свой сервер.
